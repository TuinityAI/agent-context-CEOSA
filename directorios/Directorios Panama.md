## Hospital San Fernando — Directorio Médico

URL:: https://www.hospitalsanfernando.com/medicos
TEL_HSF:: (507) 278-6300
ACREDITACIÓN:: JCI (Joint Commission International)

CEOSA opera dentro del Hospital San Fernando. Sus médicos tienen privilegios quirúrgicos en HSF.

### Servicios HSF disponibles para pacientes CEOSA

| Servicio            | Disponibilidad |
| ------------------- | -------------- |
| Sala de Operaciones | 24/7           |
| UCI adultos         | Sí             |
| Rx / TAC / RMN      | 24h            |
| Urgencias / ER      | 24h            |
| Laboratorio         | 24h            |
| Farmacia            | 24h            |
| Fisioterapia        | L–V            |
| Estacionamiento     | Sí (validado)  |

### Especialidades complementarias en HSF

Anestesiología · Cardiología · Endocrinología · Cirugía Vascular · Cirugía Plástica · Neurología

### Para el agente — respuestas HSF

- "¿Dónde está el hospital?" → Vía España, Ciudad de Panamá
- "¿Hay estacionamiento?" → Sí, validado
- "¿Urgencias?" → 24h, ER disponible. Para ortopedia urgente ir a urgencias HSF.
- "¿Están acreditados?" → JCI — máximo estándar internacional
- "¿Tienen UCI?" → Sí, adultos

### Proceso de cirugía en HSF con CEOSA

1. Consulta → diagnóstico + indicación
2. Pre-admisión → estudios en HSF Lab/Imagenología
3. Valoración anestésica
4. Programación de quirófano (secretaria CEOSA)
5. Admisión pre-cirugía
6. Cirugía en OR de HSF
7. Recuperación PACU → alta o habitación
8. Seguimiento en consultorio CEOSA
